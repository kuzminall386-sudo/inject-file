Утилита для внедрения данных из одного файла в другой с возможностью задания смещений и размеров. Реализована на Delphi, поставляется как консольный исполняемый файл (Windows x32).

[![Download v1.0.0](https://img.shields.io/badge/Download-v1.0.0-blue)](https://github.com/kuzminall386-sudo/inject-file/releases/download/v1.0.0/InjectFilex32.exe)


## Возможности
- Внедрение содержимого входного файла в выходной файл.
- Точное управление смещениями в обоих файлах.
- Контроль размера внедряемых данных и множителей для смещения/размера.
- Лицензия MIT вшита в бинарный файл и доступна через параметр `-license`.

## Установка и запуск
Просто скачайте `InjectFilex32.exe` и запустите из командной строки. Никаких зависимостей не требуется.

## Ограничения
Утилита собрана под Windows x32x64.
Не поддерживает одновременную работу с несколькими файлами.
Для работы требуются права на чтение/запись файлов.

## Параметры

| Параметр | Описание |
| --- | --- |
| `-i=<путь>` | Путь к входному файлу (файл, данные которого будут внедряться). |
| `-o=<путь>` | Путь к выходному файлу (файл, в который будут внедрены данные). |
| `-a=<смещение>` | Смещение во входном файле — начальная позиция для чтения данных. |
| `-b=<смещение>` | Смещение в выходном файле — начальная позиция для записи данных. |
| `-c=<размер>` | Размер данных, читаемых из входного файла (в байтах). |
| `-d=<множитель>` | Множитель размера данных — умножает значение, заданное параметром `-c`. |
| `-x=<множитель>` | Множитель смещения во входном файле — умножает значение, заданное параметром `-a`. |
| `-l=<множитель>` | Множитель смещения в выходном файле — умножает значение, заданное параметром `-b`. |
| `-h` | Показать справку. |
| `-license` | Вывести встроенный текст лицензии MIT (без внешнего файла). |

## Как работают множители
Параметры `-d=`, `-x=` и `-l=` позволяют задавать смещения и размеры в удобных единицах, не вычисляя их вручную.  
Например, если `-x=16` и `-a=0x10`, фактическое смещение во входном файле будет `0x10 * 16 = 0x100`.

## Примеры bat
InjectFilex32.exe -i=File1.bin -a=3 -c=10 -o=File2.bin -b=1 -l=512

## Условность
File1.bin = 512 байт <<сектор>>
File2.bin = 2 Гбайта <<образ диска>>

## Пояснение
**Простое внедрение — скопировать 256 байт из `File1.bin` начиная со смещения 0 в `File2.exe` по смещению 0x400:**
**Внедрение с выравниванием — чтение из входного файла со смещения `2 * 512 = 1024`, запись в выходной файл по смещению `1 * 4096 = 4096`, размер данных `4 * 512 = 2048`:**
До 4 Гигабайт внедрение данных в файл.
Сам файлы не создает.
Числа только десятичные.

## Предостережение
Не используете слишком большие значения особенно с множителем, возможно переполнение диска.
Не применяйте программу на ответственных файлах повышенного значения.
